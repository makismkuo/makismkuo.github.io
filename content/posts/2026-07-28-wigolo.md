你的 Agent 查个文档、搜个 Stack Overflow、抓个最新 API 示例——每一步都在调用云端的付费搜索 API。跑一个 research task 下来，光搜索费就够买杯咖啡了。

**Wigolo** 彻底改变了这个局面：它给 AI Agent 装上一个本地优先的 Web 大脑，搜索、抓取、爬虫、结构化提取、语义缓存、兜底调研——全部在本地运行，不花一分钱 API 费。项目地址 [github.com/KnockOutEZ/wigolo](https://github.com/KnockOutEZ/wigolo)，目前 3741 Stars，TypeScript 编写，更新极为活跃。

## 一句话就是：一个 MCP 服务器 = 整个 Web 工具箱

Wigolo 以 MCP 服务器形式运行，和 Claude Code、Cursor、Codex CLI、Gemini CLI、VS Code、Windsurf 等几乎所有主流 AI 编码工具无缝对接。装完之后，你的 Agent 就多了以下全部能力：

- **search** — 并行查询 18 个搜索引擎，自动排名融合与 ML 重排，每个结果附带可解释的评分
- **fetch** — 加载 URL，遇到反爬自动启用无头浏览器，返回干净 Markdown + 元数据
- **crawl** — 多页面 BFS/DFS 爬虫，支持 robots.txt、速率限制、重复内容去重
- **extract** — 结构化提取页面中的表格、JSON-LD、Schema.org 数据
- **cache** — 所有已查询内容持久化本地，关键字和语义双通道检索，离线也能用
- **find_similar** — 基于关键字 + 语义 + 实时 Web 三路融合的相似页面发现
- **research** — 自动分解问题 → 多路并行搜索 → 抓取来源 → 合成带引用的报告
- **agent** — 全自动信息采集循环：规划 → 搜索 → 抓取 → 提取 → 综合
- **diff / watch** — 页面变化检测，通过 Webhook 推送更新

## 为什么值得关注

市面上给 Agent 用的 Web 工具不是没有，但 Wigolo 的设计哲学跟它们有本质区别：

**零成本，零妥协。** 排名模型、Embedding 向量化、浏览器引擎全部在你的硬件上运行。首次安装下载约 1.5GB（浏览器引擎 + 模型），之后每次查询零费用。作为对比，Tavily 按查询计费，Exa 按用量计费，Firecrawl 每月有免费额度限制——Agent 发起查询是按批次的，一个 research 循环轻松几十次调用，只有 Wigolo 能从 $0 开始永远 $0。

**结果诚实透明。** 每个搜索结果都附带字节精确的原文摘要、可解释的评分分解、以及搜索引擎的健康状态。失败的抓取不会被静默吞掉——`blocked_by_challenge` 会明确标注。Agent 知道自己站在什么质量的地基上。

**任何展示层都接得上。** MCP 是最自然的入口，但也支持纯 REST API、TypeScript/Go/Python SDK、LangChain/CrewAI/LlamaIndex/Vercel AI SDK 框架集成。甚至可以从终端直接调用——`wigolo search "..." --json`。一个工具栈，覆盖所有场景。

## 简单实践

```bash
# 一键安装
npx wigolo init

# 同时配置 Claude Code 和 Cursor
npx wigolo init --agents=claude-code,cursor

# 检查健康状态
npx wigolo doctor

# 加个免费 Gemini Key 让研究工具写完整的合成报告
export WIGOLO_LLM_PROVIDER=gemini
export GEMINI_API_KEY=<免费 Key>
```

15 秒后用 `wigolo search "fastapi websocket best practices"` 就能搜到结果——无需注册，无需 API Key，没有账单。

## 总结

Wigolo 不是某个付费搜索 API 的免费平替——它在架构上就不是一个东西。它把搜索、抓取、提取、缓存、相似发现、自动化调研整合成一个内聚的 Web 层，按 MCP 协议暴露给 Agent，所有核心能力离线运行、按需加载、零成本无限次调用。

如果你的 AI 编码 Agent 需要频繁查询 Web，Wigolo 可能是今年你装的最值的一个工具——因为它根本不花钱。
