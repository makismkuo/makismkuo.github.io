如果你同时在用 Claude Code、Cursor、Codex CLI、Gemini CLI……那你大概率遇到过这个场景：月底一看账单，根本不知道钱花在了哪个 Agent 身上。

**Tokscale** 就是来终结这个烦恼的。它是一个开源的 CLI 工具，能自动发现你本地所有 AI 编码 Agent 的日志数据，汇总成统一的 Token 使用报告——不用改任何工作流，装了就能跑。项目地址 [github.com/junhoyeo/tokscale](https://github.com/junhoyeo/tokscale)，MIT 协议，目前 4269 Stars，由韩国开发者 junhoyeo 维护，更新极其活跃。

## 自动发现，零配置

Tokscale 最让我惊喜的就是自动发现能力。它会扫描 `~/.local/share/opencode/`、`~/.claude/`、Cursor 的 SQLite 数据库、Codex 的日志目录等常见路径，自动识别你装了哪些 Agent，然后统一汇总。

目前覆盖 30+ 个平台：Claude Code、Codex CLI、Copilot CLI、Cursor IDE、Gemini CLI、OpenCode、Amp、Codebuff、Droid、OpenClaw、Hermes Agent、Pi、Kimi CLI、Qwen CLI、Roo Code、Cline、Zed、Warp/Oz、Junie、MiMo Code、Trae、Kiro、Goose、Grok Build——几乎囊括了市面上所有主流 AI 编码工具。无论你用 Cursor 写完前端再切到 Claude Code 修后端，Tokscale 都能串起来算总账。新模型发布后，定价通过 LiteLLM 实时抓取，还支持 OpenRouter 和 Cursor 专属定价回退，永远保持最新的计费标准。

## 不只是统计

安装后输入 `npx tokscale` 即可启动基于 Ratatui 构建的交互式 TUI，核心功能包括：

- **概览面板**：总 Token 消耗、总费用、模型分布柱状图，一目了然
- **多维查看**：按模型、按天、按小时查看，甚至支持每分钟粒度的视图
- **贡献图**：GitHub 风格的热力图，哪天用得猛一眼就看到了
- **任务归因**：LLM 驱动的自动会话摘要，能告诉你钱花在了哪些具体的开发任务上
- **社交排行榜**：可选提交数据到全球公共排名，看看自己在全球 AI 开发者中的使用量级
- **JSON 导出**：方便接入自己的仪表盘或分析系统

所有数据解析和聚合引擎用 Rust 实现，比纯 Node.js 快 10 倍，哪怕积累了几个月的大日志文件也毫不卡顿。

## 极简示例

```bash
# 一句话启动完整 TUI
npx tokscale@latest

# 指定视图
npx tokscale models    # 只看模型维度
npx tokscale monthly   # 每日消费趋势

# 导出 JSON
npx tokscale --json > report.json

# 轻量模式（纯表格，适合 CI/管道）
npx tokscale --light
```

第一次运行就出结果——不配 API Key、不改配置文件，它会自己发现所有日志。需要 Node.js 或 Bun，没有其他外部依赖。

## 为什么值得关注

AI 编码工具越来越多，每个都有自己的计费逻辑。Tokscale 的价值不在于"又一个仪表盘"，而在于它用统一的视图让你对 AI 花费有了真实的掌控感。团队负责人可以用 JSON 导出做成本分摊，个人开发者能直观看到哪种工具性价比最高。

而且这个项目本身也是 Rust + TUI 的绝佳参考实现——代码质量高、文档齐全、CI 完善。于情于理，都值得 Star 和尝试。
